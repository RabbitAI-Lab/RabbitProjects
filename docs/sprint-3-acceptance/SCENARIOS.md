## 双视口录制方案（幕 11/12）

Playwright `recordVideo` 为 context 级，双账号需两个 context：录制产物为**成对视频**（scene-11a-张三视口 / scene-11b-李四视口），README 注明成对观看；两幕共用一套编排（同一脚本内串行驱动两 page，时间轴对齐）。
