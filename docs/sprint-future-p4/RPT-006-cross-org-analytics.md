## 1. 概述

| 交付项 | 说明 |
| --- | --- |
| 跨组织总览 | 各组织（空间）项目数/任务吞吐/工时投入/健康分并排 |
| 对比分析 | 指定 2~N 组织同指标横向对比（雷达/条形） |
| 访问边界 | 仅 SYSTEM_ADMIN 可查全量；运营按需授权（rbac 附录 B 登记口径） |

## 2. 业务规则（BR）

| 编号 | 规则 | 说明 |
| --- | --- | --- |
| BR-01 | 组织边界 | 跨组织查询仅 SYSTEM_ADMIN；普通用户 403（防横向越权窥探他组织数据） |
| BR-02 | 只读聚合 | 本域零写路径（纯读聚合层） |

## 4. 技术架构

复用 RPT-005 引擎的指标口径；跨空间聚合服务 `cross_org_summary()`（空间
计数/任务吞吐/工时/健康分逐空间一行）+ `cross_org_compare(ids, metric)`。

| UT-02 | 越权拒 | 非 SYSTEM_ADMIN 403 |
